# frontend/

هنا شغل الواجهة (CS2 territory): شاشات الـ Login/Register، Security Dashboard،
Admin UI stub للـ policies. مش شغلك انت في CS1، بس المجلد موجود من فيز P0
عشان الفريق كله يبدأ بنفس الـ structure.

لو هتشتغل React: `npx create-react-app .` أو Vite جوه المجلد ده.
لو هتفضل .NET من الأول لآخره: ممكن Blazor بدل React (C# بدل JS).
